# strat

An attempt to show stratigraphy information using HTML/CSS with JSON data. The color scheme needs a bit of work.

## Demo pages

* https://cngodles.github.io/strat/ General Demo.
* https://cngodles.github.io/strat/40n-36-30--79W-33-38-strat.html Sample from a specific locality.

## Stratigraphy Patterns from the USGS

* https://ngmdb.usgs.gov/fgdc_gds/geolsymstd/fgdc-geolsym-sec37.pdf

`svg/manifest.json` lists every pattern code and its known suffix variants
(generated by scanning `svg/`). Two families live in there:

* `100`–`500`-series codes ship as CMYK print separations
  (`-C`, `-M`, `-K`, plus `-DO`/`-B`/`-R` overlays) — not meant to be
  referenced directly from `stratData`.
* `600`–`700`-series codes have no suffix and are the plain, web-ready
  patterns. `stratData.seq[].type` should only ever point at one of these
  (e.g. `607`, `619`, `627`, `633`, `638`).
